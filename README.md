# 灯守の物語（toudai-story）

灯台を舞台にした、ブラウザで読むインタラクティブ・ストーリーのシリーズです。
六人の登場人物それぞれの視点から章を読み進め、散らばった手がかりを照らし合わせて謎を解き、登場人物たちの本当の身分を明らかにしていきます。

**公開ページ：** https://ufo2026t.github.io/toudai-story/

## 収録作品

| | 作品 | 時代と舞台 |
|---|---|---|
| 第一部 | 『灯の還る夜』 ― 帰らぬ舟にも、道しるべ。 | 昭和の面影を残す、噴火で無人となった島の灯台 |
| 第二部 | 『星還りの灯』 ― 星の海にも、灯はひとつ。 | 西暦2187年、撤去を目前にした宇宙の航路標識ステーション |

第二部の六人は名前も身分も第一部とは別の人物ですが、それぞれ第一部の誰かの特徴を受け継いでいます。どちらの作品から読んでもかまいません（第一部からがおすすめです）。

## 遊び方

- 各作品は四つの「幕」と終章からなります。各幕には六人それぞれの視点の章があり、好きな順に読めます。
- 六人全員の章を読み終えると「幕間の謎」が現れ、解くと次の幕へ進めます。
- 章の途中には、選択肢・問い・小さなゲーム（配線パズル、写真機のピント合わせ、ラジオの選局、モールス信号、拓本、暗号解読、星をつなぐ、照準合わせなど）があります。
- 重要な記述は「手がかり帳」に自動で記録されます。登場人物の正体が判明すると「人物ファイル」が書き換わります。
- 右上の「設定」から、表示スタイル（夜灯・和紙・黄昏・深海・墨）、書体、文字の大きさ、行間、文章の現れ方、背景の演出、効果音を選べます。

## ローカルで読む

ビルドやサーバーは不要です。リポジトリを取得して `index.html` をブラウザで開くだけで読めます。

```sh
git clone https://github.com/ufo2026t/toudai-story.git
```

ローカルのサーバーで確認したい場合は、たとえば次のように起動します。

```sh
npx serve .
# または
python -m http.server 8000
```

## 外部との通信について

このサイトは外部と一切通信しません。

- `index.html` の Content-Security-Policy で、ネットワーク接続・外部スクリプト・外部フォントの読み込みを禁止しています。
- フォントは端末に入っているシステムフォント（游明朝、ヒラギノ、メイリオなど）だけを指定しています。
- 効果音は音声ファイルを使わず、Web Audio でその場で合成しています。
- 進行状況と設定は、ブラウザの localStorage にだけ保存されます。

## ディレクトリ構成

```
index.html              ページ本体（CSP・スクリプトの読み込み順）
favicon.svg             アイコン
css/style.css           画面のスタイルと表示スタイル（テーマ）
js/core.js              作品の登録、進行状況の保存、書式、効果音
js/engine.js            画面遷移・章の描画・幕間の謎・設定
js/games.js             ミニゲーム（第一部）
js/games-extra.js       ミニゲーム（第二部で追加したもの）
js/data/                第一部『灯の還る夜』の登場人物・本文
js/data2/               第二部『星還りの灯』の登場人物・本文
.github/workflows/      GitHub Pages へのデプロイ
```

本文データは幕ごとのファイルに分かれています。各章は段落の文字列と、選択肢（`choice`）・問い（`quiz`）・ゲーム（`game`）・手がかり（`clue`）・正体判明（`reveal`）などのブロックの並びで書かれています。

## GitHub Pages へのデプロイ

`master` ブランチに push すると、`.github/workflows/deploy-pages.yml` が公開用のファイル（`index.html`、`favicon.svg`、`css/`、`js/`）をまとめて GitHub Pages にデプロイします。

初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
